Selected Projects주요 프로젝트003

Anomaly detection

Offshore gas turbine early warning해상 가스터빈 조기 경보

99 sensors, 105,264 timestamps, a 48-hour warning horizon. Recast as event-level early warning rather than point-wise classification: a Noise Index with Otsu thresholding drops sensors unrelated to failure, per-sensor Conv1D autoencoders are pruned on validation loss, and normalised errors are fused by max with consecutive-k filtering to suppress false alarms. Trained on healthy operation only.99개 센서, 105,264 시점, 고장 48시간 전 경보가 목표. point-wise 분류 대신 event 단위 조기 경보로 문제를 재정의했습니다. Noise Index와 Otsu threshold로 고장과 무관한 센서를 제거하고, 센서별 독립 Conv1D 오토인코더를 validation loss 기반으로 pruning했으며, 정규화한 복원 오차를 max fusion과 consecutive-k 필터로 결합해 오경보를 억제했습니다. 정상 운전 데이터만으로 학습합니다.

  • 99 sensors
  • 105,264 steps
  • T−48h horizon
Forecasting · LLM

News-conditioned aluminium price forecasting뉴스 결합 알루미늄 가격 예측

17,093 articles (2010–2025) cleaned to 10,531, de-duplicated by TF-IDF similarity, then filtered to 4,278 price-relevant items by Llama-3. Topics via SBERT / UMAP / HDBSCAN / KeyBERT with an LLM-generated upper hierarchy; ModernFinBERT embeddings joined to price and exogenous series in an iTransformer. The LLM is used as a feature engine, not an answer generator.2010–2025년 기사 17,093건을 10,531건으로 정제하고 TF-IDF 유사도로 중복 보도 편향을 완화한 뒤, Llama-3로 가격 관련성을 판별해 4,278건을 남겼습니다. SBERT·UMAP·HDBSCAN·KeyBERT로 토픽을 구성하고 상위 계층은 LLM으로 생성했으며, ModernFinBERT 임베딩을 가격·외생변수와 함께 iTransformer에 결합했습니다. LLM을 답변 생성기가 아니라 feature 엔진으로 씁니다.

  • MAE 117.72 (naive 128.85)
  • R² 0.34 (naive 0.20)
Forecasting · Evaluation

Wind power forecasting under a step-shaped metric계단형 지표 아래의 풍력 발전량 예측

Half the score came from a step function on error rate, so I approximated it with a smooth sigmoid surrogate and optimised it directly. Curtailment periods were identified from per-turbine SCADA output and their suppressed labels removed. After the leaderboard closed, a control experiment resampled the scoring window 2,000 times with predictions frozen: this metric's sampling noise is 5.5× that of a standard accuracy metric.배점의 절반이 오차율 계단 함수였기 때문에, 이를 시그모이드로 매끄럽게 근사한 대리 손실을 설계해 학습 목적함수에 직접 넣었습니다. 터빈별 SCADA 출력으로 정지 구간을 판정해 눌린 라벨을 학습에서 제거했습니다. 리더보드 종료 후에는 예측을 고정한 채 채점 구간만 2,000회 바꾸는 통제 실험으로, 이 지표의 표본 잡음이 정확도 지표의 5.5배임을 측정했습니다.

Manufacturing

Semiconductor defect prediction (SECOM)반도체 공정 결함 예측 (SECOM)

Severe class imbalance where a miss costs far more than a false positive. Six oversampling schemes compared; ADASYN synthesised the minority boundary best. PCA compressed 33 variables to 24 components at 91% retained variance, and a soft-voting ensemble over RF, GBM, SVM and XGBoost was thresholded at 0.48 from the precision–recall curve. SHAP, PFI and PDP name the variables behind each call.불량이 극히 적고, 미검이 오검출보다 훨씬 치명적인 문제였습니다. 6종의 오버샘플링을 비교해 소수 클래스 경계를 가장 정교하게 합성한 ADASYN을 택했고, PCA로 33개 변수를 변동성 91% 보존하며 24개 주성분으로 압축했습니다. RF·GBM·SVM·XGBoost의 Soft Voting 앙상블에 Precision-Recall Curve 기준 임계값 0.48을 적용했고, SHAP·PFI·PDP로 판정 근거 변수를 해석했습니다.

On-device AI

On-device agent with revocable memory철회 가능한 기억을 가진 온디바이스 에이전트

Built with no GPU, no external LLM API and no network. Every memory is tagged with source, authority, scope and lifetime, and derivations are tracked so a user's retraction withdraws what was derived from it while leaving unrelated rules intact. Five experiments showed the small on-device model's apparent 70% accuracy was response bias, so it was given veto power only, with a rule auditor as fallback.GPU·외부 LLM API·네트워크가 모두 금지된 조건에서 구현했습니다. 모든 기억에 출처·권위·범위·수명을 태그하고 파생 관계를 추적해, 사용자의 철회가 파생 결과물까지 정확히 거둬들이되 무관한 규칙은 보존하도록 설계했습니다. 다섯 차례 실험으로 온디바이스 소형 모델의 겉보기 70% 정확도가 응답 편향임을 밝혀낸 뒤, 모델에는 거부권만 부여하고 규칙 감사관으로 넘어가게 재설계했습니다.
